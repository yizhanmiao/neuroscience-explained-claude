## Notebooks

| Folder | Status |
|--------|--------|
| [`generated/`](generated/) | Drafted by Claude — may contain errors or imprecisions |
| [`reviewed/`](reviewed/) | Human-proofread — considered reliable |

## Getting Started

**Install Pluto** (once):
```bash
julia -e 'import Pkg; Pkg.add("Pluto")'
```

**Launch the notebook server:**
```bash
julia -e 'import Pluto; Pluto.run()'
```

Then open any `.jl` notebook from the Pluto file browser. Each notebook installs its own dependencies on first run.
